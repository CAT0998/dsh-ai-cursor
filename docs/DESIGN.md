# 设计文档 · dsh-ai-cursor / AI 鼠标

> 本文同时是给二次开发者的架构说明，也是提交到插件市场前的功能清单。

## 1. 目标

给 DeepSeek Harness 的 Agent 一只**属于自己的第二个光标**，并提供一个**浮动、可隐藏的控制菜单栏**，
让用户随时调节它、暂停它、限制它的权限。真实鼠标指针全程不被移动。

```
┌──────────── DSH 宿主进程（Node / Cordis） ────────────┐
│  src/index.ts  ── 注册 ai_mouse_* 工具 + 权限门禁      │
│        │  JSON 行协议（stdin/stdout）                  │
└────────┼───────────────────────────────────────────────┘
         ▼
┌──────────── ai-mouse-overlay.exe（Rust / Win32）───────┐
│  光标窗口 AiMouseOverlay  分层 · 点击穿透 · 不进截图    │
│  面板窗口 AiMousePanel    分层 · 可交互 · 可折叠        │
└────────────────────────────────────────────────────────┘
```

## 2. 两个窗口

| | 光标窗口 `AiMouseOverlay` | 面板窗口 `AiMousePanel` |
|---|---|---|
| 扩展样式 | `LAYERED｜TRANSPARENT｜TOOLWINDOW｜NOACTIVATE｜TOPMOST` | `LAYERED｜TOOLWINDOW｜NOACTIVATE｜TOPMOST` |
| 点击 | 穿透，永不抢焦点 | **接收**鼠标事件（自己画 Hit-Test） |
| 尺寸 | 360×240（tip 在 200,44） | 452×396 展开 / 132×40 收起 |
| 绘制 | GDI 4× 超采样 → 缩采样 → `UpdateLayeredWindow` | 同上，2× 超采样 |
| 截图 | `WDA_EXCLUDEFROMCAPTURE`（可切换） | 同左 |

分层窗口的命中测试按 alpha 走，所以圆角外、透明区天然不挡鼠标。

## 3. 面板内容（菜单栏）

```
┌──────────────────────────────────────────┐
│ ◉ AI 鼠标                      ─     ✕  │  ← 拖动条（整条可拖）
├──────────────────────────────────────────┤
│ [ 显示 ][ 隐藏 ][ 停止 ][ 启用 ]          │  ← 主操作
├──────────────────────────────────────────┤
│ AI 提示            [开][关]      透明度 70%│
│ ━━━━━━━━━━━●━━━━━━━━━━━━━━━━━━━━━━━━━ │  ← 透明度滑条 15%~100%
│ 颜色  ● ● ● ● ● ● ● ●             #4FC3F7│
├──────────────────────────────────────────┤
│ 造型   [鲸鱼][圆点][箭头]         大小 100%│
│ ━━━━━━━●━━━━━━━━━━━━━━━━━━━━━━━━━━━━ │  ← 大小滑条 60%~200%
├──────────────────────────────────────────┤
│ 权限等级 [停止][只读][操作][管理员]        │
├──────────────────────────────────────────┤
│ 可见 · (900,520) · fps 38 · 权限 管理员   │
└──────────────────────────────────────────┘
```

- **可隐藏**：`─` / `✕` 折叠成右下角小胶囊（`132×40`），点胶囊展开；`ai_mouse_panel{visible:false}`
  可整块隐藏。
- **拖动**：按住顶栏任意处拖动，位置写回状态。
- **命中测试**：`layout()` 同时产出绘制矩形与 `Hit` 列表，画和点用同一份数据，不会错位。

## 4. 权限等级（0–3）

| 等级 | 名称 | AI 可以做什么 |
|---|---|---|
| 0 | 停止 | `status` + 系统级命令（见下） |
| 1 | 只读 | + `show` / `hide` / `panel` |
| 2 | 操作 | + `move` |
| 3 | 管理员 | + `label` / `theme` / `badge` / `opacity` / `color` / `scale` / 降权限 |

规则：

- **人高 AI 低**：面板（人）可任意设置；AI 通过 `permission` 命令**只能降、不能升**。
  想恢复只能由人在面板上点「启用」或「管理员」。
- 双保险：TS 层按工具 `minLevel` 先拦一次，Rust 层再按命令 `min_perm` 拦一次。
- 「停止」= `permission=0` 并隐藏光标；「启用」= 恢复到 `max(上一次, 2)`。
- **系统级例外**：`affinity`（是否进截图）/ `idle`（自动隐藏时长）/ `dump`（自测出图）/
  `quit` 在两层都**不受等级限制**——它们是宿主配置与自测通道，不是 Agent 的鼠标动作。
  因此等级 0 下 `ai_mouse_capture_visible` 仍可调用（此时光标本就隐藏，不构成越权）。
  这条例外是刻意的，文档与代码必须这样描述。

## 4.1 命中测试

顶栏是一条覆盖 `0..40` 的整宽拖拽区，几何上包住了 `─` 与 `✕`。
所以命中不能「取第一个包含点的矩形」，否则点按钮会变成拖窗口。
`pick()` 给控件排优先级：`Button|Swatch|Chip` 0 → `Slider` 1 → `Header` 2 → `Label|Sep` 3，
取优先级最高者；`Label`/`Sep` 永远不会接手点击。布局时两个顶栏按钮也先于拖拽区入栈。

## 5. 行协议（stdin / stdout，一行一个 JSON）

| 命令 | 权限 | 作用 |
|---|---|---|
| `{"cmd":"show"}` / `hide` | ≥1 | 显隐光标 |
| `{"cmd":"move","x","y","duration_ms"}` | ≥2 | 滑到绝对屏幕坐标 |
| `{"cmd":"panel","visible":bool}` | ≥1 | 显示/隐藏面板 |
| `{"cmd":"panel_expanded","expanded":bool}` | ≥1 | 展开/折叠 |
| `{"cmd":"opacity","value":0.15~1}` | ≥3 | 光标透明度 |
| `{"cmd":"color","hex":"#4FC3F7"}` | ≥3 | 主色 |
| `{"cmd":"scale","value":0.6~2}` | ≥3 | 光标尺寸 |
| `{"cmd":"badge","visible":bool}` | ≥3 | AI 提示（徽章）显隐 |
| `{"cmd":"theme","theme":"whale"\|"dot"\|"arrow"}` | ≥3 | 造型 |
| `{"cmd":"label","text":"..."}` | ≥3 | 徽章文字 |
| `{"cmd":"permission","level":0~3}` | ≥3 且只能降 | 权限等级 |
| `{"cmd":"pause"}` / `{"cmd":"resume"}` | ≥3 | 等价于 停止/启用 |
| `{"cmd":"idle","idle_ms":n}` | 系统 | 自动隐藏 |
| `{"cmd":"affinity","capture_visible":bool}` | 系统 | 是否进截图（重建窗口） |
| `{"cmd":"dump","path":"...","target":"cursor"\|"panel"}` | 系统 | 自绘一帧到 BMP（自测） |
| `{"cmd":"status"}` | 任何 | 回读状态 |
| `{"cmd":"quit"}` | 系统 | 退出 |

每条命令回一行 JSON，带同一个 `id`；`status` 额外回 `opacity/color/scale/badge/permission/panel/...`。
